# Security

Не публикуйте в этом репозитории пароли, API-токены, `.env`-файлы, ключи подписи, сертификаты или `export_credentials.cfg`.

Если вы обнаружили чувствительные данные в репозитории, не создавайте публичный issue. Свяжитесь с владельцем репозитория через его профиль GitHub и укажите только путь к файлу и тип проблемы — не копируйте сам секрет.
