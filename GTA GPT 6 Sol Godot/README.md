# Harborline — GTA GPT 6 Sol Godot

Harborline — оригинальная одиночная sandbox-игра со свободным исследованием прибрежного города, транспортом, оружием, полицией, погодой и сменой времени суток. Сюжетных миссий нет: игра сразу запускается в свободном режиме.

## Самый простой запуск

Godot и другие инструменты устанавливать не нужно.

### Windows 10/11

1. Откройте [последний релиз](https://github.com/Prokopiy8247/GTA-GPT-6-Sol-Unity-Godot-Unreal-Engine-5/releases/latest).
2. Скачайте `Harborline-Windows-x86_64.zip`.
3. Нажмите на архив правой кнопкой и выберите **Извлечь всё**. Не запускайте игру прямо из архива.
4. Откройте распакованную папку и дважды нажмите `Harborline.exe`.
5. Если Windows SmartScreen покажет предупреждение для неподписанного приложения, нажмите **Подробнее** → **Выполнить в любом случае**, только если архив скачан из релизов этого репозитория.

### macOS (Intel и Apple Silicon)

1. Откройте [последний релиз](https://github.com/Prokopiy8247/GTA-GPT-6-Sol-Unity-Godot-Unreal-Engine-5/releases/latest).
2. Скачайте `Harborline-macOS-Universal.zip` и распакуйте его.
3. Перетащите `Harborline.app` в папку **Applications/Программы**.
4. При первом запуске нажмите на приложение правой кнопкой (или `Control` + клик), выберите **Open/Открыть**, затем подтвердите запуск.

Сборка не нотарифицирована Apple, поэтому обычный двойной клик может быть заблокирован Gatekeeper. Если кнопки **Открыть** нет, перейдите в **System Settings → Privacy & Security** и разрешите запуск Harborline. Используйте только архив из релизов этого репозитория.

## Управление

| Клавиши | Действие |
| --- | --- |
| `W A S D`, мышь | Движение/руление и камера |
| `Shift` | Бег |
| `Space` | Прыжок или ручной тормоз; управление подъёмом в воздухе |
| `F` | Сесть в транспорт / выйти |
| `E` | Взаимодействие с сервисами |
| Левая/правая кнопка мыши, `R` | Атака, прицеливание, перезарядка |
| `1`–`9`, колесо мыши, `Tab` | Выбор оружия и колесо оружия |
| `M` | Карта |
| `F10` | Меню инструментов sandbox |
| `F5` / `F9` | Сохранить / загрузить |
| `Esc` | Пауза |

Полный список — в [DEVELOPMENT.md](DEVELOPMENT.md#controls).

## Запуск исходного проекта

1. Установите стандартную версию [Godot 4.7.2](https://godotengine.org/download/archive/4.7.2-stable/).
2. Скачайте репозиторий через **Code → Download ZIP** и распакуйте его или клонируйте через Git.
3. В Godot нажмите **Import**, выберите этот файл `project.godot`, затем **Import & Edit**.
4. Нажмите **F6/F5** или кнопку запуска проекта.

Если команда `godot` добавлена в `PATH`, можно дважды нажать `run_windows.bat` на Windows или `run_macos.command` на macOS.

## Сборка и проверка

В репозитории находятся готовые пресеты `export_presets.cfg` для Windows x86_64 и универсальной macOS-сборки. Для ручного экспорта сначала установите шаблоны экспорта Godot 4.7.2.

```text
godot --headless --path . --script res://gta/tools/smoke_test.gd
godot --headless --path . --export-release "Windows x86_64" build/windows/Harborline.exe
godot --headless --path . --export-release "macOS Universal" build/macos/Harborline-macOS-Universal.zip
```

GitHub Actions автоматически повторяет smoke-тест и создаёт оба архива при публикации тега `v*`.
